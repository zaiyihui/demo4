## 3. 功能特性

### 3.1 实时性能指标

| 指标 | 显示内容 | 更新频率 |
|------|---------|---------|
| CPU | 使用率、温度、状态 | 1秒 |
| GPU | 使用率、温度、状态 | 1秒 |
| 内存 | 使用率、已用/总计 | 1秒 |
| FPS | 帧率、响应时间、错误率 | 1秒 |

### 3.2 数据可视化

- **图表类型**: Canvas + Polyline
- **数据点数**: 最多60个点
- **更新频率**: 1秒
- **网格线**: 5条水平参考线

### 3.3 告警系统

| 告警规则 | 触发条件 | 严重程度 |
|----------|---------|---------|
| HighCpuUsage | CPU > 90% 持续30秒 | Warning |
| HighGpuTemperature | GPU温度 > 85°C 持续60秒 | Error |
| HighMemoryUsage | 内存 > 90% 持续60秒 | Warning |
| LowFps | FPS < 30 持续10秒 | Warning |
| CriticalTemperature | CPU温度 > 95°C 持续10秒 | Critical |

### 3.4 历史数据查询

- **时间范围**: 15分钟、30分钟、1小时、6小时、24小时
- **数据存储**: 内存中保存最近1000个数据点
- **刷新机制**: 手动刷新按钮

## 5. 系统集成

### 5.1 服务注册

在 `App.axaml.cs` 中添加了以下服务注册:

```csharp
// 新增核心服务
services.AddSingleton<ILogService, LogService>();
services.AddSingleton<IPerformanceMonitorService, PerformanceMonitorService>();
services.AddSingleton<IBackupService, BackupService>();
services.AddSingleton<ILocalizationService, LocalizationService>();
services.AddSingleton<ICloudSyncService, CloudSyncService>();
services.AddSingleton<IAIService, AIService>();
services.AddSingleton<IPluginService, PluginService>();
```

### 5.2 快捷键集成

在 `MainWindow.axaml.cs` 中添加:

```csharp
case Key.F4:
    OpenPerformanceDashboard();
    break;
```

### 5.3 依赖关系

```
PerformanceDashboardViewModel
    ├── IPerformanceMonitorService (必需)
    ├── IHardwareMonitorService (必需)
    └── ILogService (必需)
```

## 10. 使用指南

### 10.1 打开性能面板

**方法1**: 快捷键
- 在主窗口中按 `F4` 键

**方法2**: 代码调用
```csharp
var dashboard = new PerformanceDashboardWindow();
var viewModel = new PerformanceDashboardViewModel(
    performanceMonitor,
    hardwareMonitor,
    logService);
dashboard.SetViewModel(viewModel);
dashboard.Show();
```

### 10.2 功能操作

| 操作 | 方法 |
|------|------|
| 切换时间范围 | 点击下拉框选择 |
| 过滤指标 | 勾选/取消勾选复选框 |
| 刷新数据 | 点击刷新按钮 |
| 导出数据 | 点击导出按钮（待实现） |
| 关闭面板 | 点击关闭按钮或按ESC |

### 10.3 告警处理

1. **查看告警**: 在底部告警列表查看
2. **告警颜色**:
   - 🔴 Critical: 严重告警
   - 🟠 Error: 错误告警
   - 🟡 Warning: 警告告警
   - 🔵 Info: 信息告警
3. **处理建议**: 根据告警消息采取相应措施
