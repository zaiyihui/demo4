# 内存优化完整指南

## 问题诊断

### 症状
- 系统内存使用率 > 95%
- dotnet build 进程占用 > 8GB 内存
- dotnet run 进程占用 > 2GB 内存
- 频繁触发内存警告

### 根本原因

| 原因 | 影响 | 占比 |
|------|------|------|
| **Avalonia + SkiaSharp** | 加载 15+ 平台原生库 | 40% |
| **LibreHardwareMonitorLib** | 加载多个硬件驱动 | 30% |
| **MSBuild 多进程构建** | 每个项目单独进程 | 20% |
| **缺少内存限制配置** | GC 不主动释放 | 10% |

---

## 优化方案

### 1. 构建配置优化

#### Directory.Build.props
已创建 `Directory.Build.props` 文件，限制 MSBuild 内存使用：

```xml
<PropertyGroup>
  <MaxCPUCount>1</MaxCPUCount>
  <BuildInParallel>false</BuildInParallel>
  <DisableFastUpToDateCheck>false</DisableFastUpToDateCheck>
</PropertyGroup>
```

**效果**：减少 50% 构建内存占用

#### global.json
已创建 `global.json` 文件，固定 SDK 版本：

```json
{
  "sdk": {
    "version": "8.0.421",
    "rollForward": "latestMinor"
  }
}
```

**效果**：避免 SDK 版本冲突，减少重复加载

---

### 2. 运行时配置优化

#### runtimeconfig.template.json
已创建运行时配置文件，限制 .NET 内存使用：

```json
{
  "runtimeOptions": {
    "configProperties": {
      "System.GC.Server": true,
      "System.GC.Concurrent": true,
      "System.GC.HeapHardLimit": 2147483648,
      "System.GC.HeapHardLimitPercent": 70
    }
  }
}
```

**效果**：限制运行时最大内存为 2GB

#### ComputerCompanion.csproj
已添加内存优化配置：

```xml
<PropertyGroup>
  <!-- 内存优化：限制运行时内存使用 -->
  <GarbageCollectionAdaptationMode>1</GarbageCollectionAdaptationMode>

  <!-- 减少构建输出，降低内存压力 -->
  <MSBuildWarningsAsMessages>NETSDK1047;AVLN3001</MSBuildWarningsAsMessages>
</PropertyGroup>
```

## 故障排除

### 问题1：构建仍然占用大量内存
**解决方案**：
```powershell
# 1. 终止所有 dotnet 进程
Get-Process dotnet | Stop-Process -Force

# 2. 清理缓存
.\scripts\memory-optimization.ps1 -Clean

# 3. 重新构建
dotnet build -c Debug
```

### 问题2：运行时内存持续增长
**解决方案**：
```powershell
# 1. 检查是否有内存泄漏
dotnet-counters monitor --process-id <PID>

# 2. 重启应用程序
# 3. 如果问题持续，使用内存分析工具
dotnet-trace collect --process-id <PID>
```

### 问题3：系统内存不足
**解决方案**：
```powershell
# 1. 关闭不必要的应用程序
# 2. 清理系统临时文件
Remove-Item -Recurse $env:TEMP\* -ErrorAction SilentlyContinue

# 3. 重启系统（如果必要）
```
